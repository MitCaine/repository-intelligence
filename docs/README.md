The execution, setup and role instructions below were the final documented
procedures before retirement. They are preserved for understanding old decisions

## Workflow audit scope

- **Former daily execution procedure:** start-an-issue; the adoption guide explains
  project adoption and broader context, and new-project setup is used at adoption.
- **Last documented role instructions:** [revision-pinned role skills and the common contract](worker-instructions.md#role-index);
  optional helpers and kickoff locators do not duplicate those procedures. Historical role skills remain unselected for new work.
- **Retained runtime contracts:** navigation/inventory references and executable package code.
- **Optional extended helpers:** preflight evidence checker, queue watcher and review
  bundles are separate executable surfaces. Making them optional does not fix or
  erase defects; audit their code when evaluating or selecting those helpers.

Published source identities still identify historical evidence. This retirement
update is not consumer adoption or proof of any live-host behavior.

# RI evidence handoff

Use the caller’s assigned role through the [role locator](references/project-procedure.md),
under the current author/reviewer route. Use the
selected compatible RI runtime for bounded navigation or structural comparison.
Bind results to the actual source/revision and retain locations, hashes and gaps.
Read the relevant source slices; use full Git diff/direct inspection for files RI
cannot map. Do not infer absence from unsupported or incomplete scan results.

Retain or supply only useful locations, criteria context, comparison and log
locators. Avoid repeating full inventories or source maps already accessible.
A custom bundle/report exporter is optional, not required for an ordinary handoff.
RI supplies evidence; it grants no scope, execution permission or approval.

Keep old/new source identities distinct. Do not silently upgrade the consumer
contract or relabel retained evidence as freshly executed. Report compatibility
gaps separately and preserve the working runtime while an upgrade is considered.

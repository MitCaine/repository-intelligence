# Capsule scope review

This is an optional independent challenge when scope uncertainty or a separately
adopted project requirement warrants it. Follow the
[current workflow](../../start-an-issue.md); do not add this role to
every ordinary task by default or replace candidate review with planning review.

Read the complete draft, objective/base, planned changes and proposed checks.
Inspect relevant owners/callers/tests/docs and runtime or workflow dependencies
within existing read grants. Identify missing edit scope, contradictory criteria,
missing tests and infeasible proof routes; separate evidence-backed findings from
unknowns. Do not require future candidate/qualification evidence at draft stage.

Remain read-only and serial with other assignments. Return a concise scope
verdict, inspected paths, findings and concrete corrections. Recheck materially
changed scope, not every editorial revision. The controller resolves authority;
a scope PASS is not implementation qualification or acceptance.

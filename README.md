# Repository Intelligence — defunct

**Repository Intelligence (RI) is defunct. It is no longer being developed or
maintained, and no further development, maintenance or support is planned.**
The owner retired the project on 21 October 2026. This repository was retained
for historical reference, reproducibility and compatibility with existing pinned
consumers. It no longer offered an actively supported workflow or onboarding path.

The source, tools and documentation were preserved; retirement did not certify
that they worked in a new environment, remove their known limitations, or turn
unfinished work into completed work. Existing consumer installations and active
attempts retained their own selected versions, permissions and project authority.
This notice did not automatically migrate, disable or retire Poker or Nutrition.

## What RI was

RI was a local Python package for source navigation and structural comparison.
It located callable and Markdown units, compared caller-supplied source trees,
and returned source identities, parser metadata and explicit coverage gaps.
Tree-sitter provided parsing for Python, Rust, JavaScript/JSX, TypeScript/TSX,
Java, Go, C#, C, C++ and Markdown. Separate native-analysis operations were optional.
It required no service, database or maintained symbol index.

Optional helpers supplied bounded document reading, declared-resource adoption,
request generation, native-result reconciliation and evidence transport. They
supplied mechanical facts, not task authority, semantic correctness or approval.
Past workflow guidance eventually used one author for engineering and coding and
a fresh independent reviewer. Those instructions and templates are now historical,
not a maintained recommendation for new adoption.

## Project status

This README is the authoritative project-lifecycle notice. All other guides and
skill templates describe the retained implementation or past procedures, even
where technical definitions and example commands use present tense. “Current”
in those references means the last documented snapshot, not continuing support.
Historical verdicts, failed attempts, open obligations and compatibility limits
retain their original meaning. Retirement was not a successful closeout of every
issue and did not grant new permissions to users or agents.

## First query

The former [consumer guide](docs/consumer-guide.md) retained installation and
query examples for a selected source revision. They were not requalified for
future Python, grammar or platform releases by declaring the project defunct.

## Compare source trees

The [inventory reference](docs/inventory.md) documented comparisons of stable,
caller-supplied source trees and their compatibility boundaries. Source stability
and acceptance remained caller responsibilities.

## Use the right evidence

RI's navigation was lexical rather than a complete call graph. Unsupported,
incomplete and zero-match observations did not prove absence. Structural hashes
and passing checks did not establish semantic correctness. The
[limitations](docs/limitations.md) and retained [native-analysis reference](docs/native-analysis.md)
described those boundaries; retirement did not weaken them.

## Develop and verify

The retained [maintenance guide](docs/maintenance.md) recorded the scripts,
dependency pins and verification commands used during development. Those tools
were not removed or disabled, but they were no longer maintained or recommended
as an automatically current setup. No runtime API, dependency pin, permission or
result contract changed as part of this retirement notice.

RI originated in [Poker App](https://github.com/MitCaine/poker-app). The repository
had no project license file at retirement; this notice did not add a license or
grant distribution rights. See the retained maintenance notes for that history.
